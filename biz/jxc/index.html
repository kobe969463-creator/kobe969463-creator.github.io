什么场景

一家做五金建材批发的小仓库（公司名、数据都是编的），常卖的货 30 多种：螺丝、水管、电线、开关、玻璃胶、石膏板、水泥。客户是装修公司、水电师傅和工地，每天开十来张送货单，隔一两天来一车货。

原来怎么干

开单用复写的三联送货单手写，单价靠记，晚上再把当天的单子一张张抄进 Excel 算库存。抄漏、写错单价是常事，库存表跟仓库里对不上。

电线、门锁这些快卖完了没人注意，客户来要货才发现没了，临时打电话找供应商调。月底对账、客户问「上个月那单送了几卷」，都要翻一沓单子。

做了什么

  1. 出库开单选客户带出地址电话，选商品带出售价和现在的库存；数量超过库存直接拦住，不会开出发不了的单
  2. 库存自己扣、自己加开出库单扣，到货登记入库加，不用晚上再抄一遍
  3. 低于安全库存标红每样货设一条安全库存线，掉下去在工作台和库存页标红；一键出补货单，到货后一键带进入库
  4. 按单号查单、打印送货单（二等分三联，针式打印机）、出库单 / 入库单 / 补货单（A4），金额自动转大写，带签字栏；打印时只出单据
  5. 回单签收客户签回来的回单点一下标成已签收，还没签回来的单一眼看到
  6. 进销存报表按商品看期初、入库、出库、结存和毛利，按本月 / 本周 / 今天看，能导出 Excel 给财务

能接到哪

电脑、手机浏览器针式打印机 / 三联纸A4 激光打印机扫码枪老 Excel 导进来导出给财务多个仓库企业微信 / 小程序里打开

单据上要哪些字段、排成什么样，照你们现在用的纸来，不用换打印纸；商品、客户、价格从你们的 Excel 导进来。

顺带：送货、老板在手机上看

送货师傅在手机上查单、点回单签收；老板在手机上看今天出了多少货、哪些货要补。同一套东西，电脑和手机都能开。
